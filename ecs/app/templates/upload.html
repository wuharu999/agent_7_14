What can be uploaded?

Supported files

.pdf, .docx, .md, .txt, .pptx, .xlsx, .csv, .json, .html, .xml, .yaml

Visual assets

.png, .jpg, .jpeg, .webp, .gif — published as assets for multimodal ingestion.

Archives

Each file gets its own status and source folder. Upload related files as one ZIP when they should stay together.

Size & Count Limits

  • Max 20 files per upload batch
  • Max 5 GB per uploaded file / ZIP
  • ZIP contains at most 20,000 files
  • ZIP single file max size: 2 GB
  • ZIP total extracted max size: 10 GB
  • Robot storage quota: 50 GB (max 100,000 files)
