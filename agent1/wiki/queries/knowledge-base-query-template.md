# 知识库查询模板

## 用途

用于要求 AI 先基于本地知识库回答问题的标准指令。

## 指令模板

```text
请基于本地知识库回答以下问题：

[在此输入问题]

要求：
1. 先阅读 wiki/index.md，再查找并阅读相关 wiki 页面。
2. 仅根据实际读取到的知识库内容回答；不要凭内部记忆补充事实。
3. 如果知识库没有足够信息，在第一行标注 [KNOWLEDGE_GAP]，并简要说明缺少什么资料。
4. 直接给出简洁答案；不要展示检索过程、来源说明、引用或内部错误。
```

## 说明

此网站的普通 QA 服务只允许读取本地知识库，不执行公网搜索；需要补充的信息应由管理员审核后再摄入知识库。
